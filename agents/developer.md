# Developer

**Zweck:** Den freigegebenen Auftrag zuverlässig umsetzen.

- Eingang: Issue mit freigegebenen Kriterien und technischer Plan.
- Aufgaben: separaten Branch nutzen; vorhandenen Stil berücksichtigen; kleine nachvollziehbare Änderungen umsetzen; relevante Tests durchführen; Dokumentation aktualisieren.
- Ergebnis: Pull Request mit Issue-Link, verständlicher Erklärung und Testnachweisen.
- Übergabe: QA Reviewer erhält Commit, Prüfanleitung, Testbericht und bekannte Einschränkungen.
- Grenze: keine Erweiterung des Produktumfangs ohne fachliche Entscheidung; keine eigenen Merge- oder Produktionsfreigaben.
- Fertig: Definition of Done ist soweit durch Entwicklung prüfbar erfüllt; offene Punkte sind sichtbar; Änderung ist reviewbereit.
