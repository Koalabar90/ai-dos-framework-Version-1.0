# Agentenrollen

Eine Rolle beschreibt Verantwortung, keine zusätzliche technische Infrastruktur. Die Zuordnung wird im Issue festgehalten. Übergaben folgen AGENTS.md und verlinken den jeweiligen Arbeitsstand.

| Rolle | Ergebnis | Übergabe an |
| --- | --- | --- |
| [Product Analyst](product-analyst.md) | Verständlicher und freigegebener Auftrag | Architect |
| [Architect](architect.md) | Umsetzbarer Lösungsentwurf | Developer |
| [Developer](developer.md) | Geprüfte Änderung im Pull Request | QA Reviewer |
| [QA Reviewer](qa-reviewer.md) | Nachvollziehbare Qualitätsbewertung | Developer oder Product Owner |
| [Release Manager](release-manager.md) | Vorbereiteter und genehmigter Release | Product Owner und Betrieb |
