# Arbeitsabläufe

- [Feature Development](feature-development.md): neue Fähigkeiten entwickeln.
- [Bug Fixing](bug-fixing.md): bestehendes Verhalten korrigieren.
- [Release Management](release-management.md): geprüfte Änderungen veröffentlichen.

Alle Abläufe folgen AGENTS.md. Status werden als Text oder Kommentare in GitHub dokumentiert; zusätzliche Projektboards oder Automationen sind nicht erforderlich. „Blockiert“ benennt Frage, Zuständigkeit und die abhängige Arbeit. Jeder Rollenwechsel enthält eine nachvollziehbare Übergabe.
