# Dokumentvorlagen

Vorlagen kopieren, Platzhalter ersetzen und im Projekt versionieren. Unzutreffende Punkte mit Begründung als „nicht zutreffend“ markieren. Leere Kästchen sind keine Freigaben.

| Vorlage | Empfohlener Ablageort im Projekt |
| --- | --- |
| [Produktbrief](product-brief.md) | `docs/product-brief.md` |
| [Feature Request](feature-request.md) | GitHub-Issue |
| [Architecture Decision Record](architecture-decision-record.md) | `docs/decisions/ADR-001-kurztitel.md` |
| [Test Report](test-report.md) | `docs/test-reports/<issue>-<stand>.md` |
| [Release Checklist](release-checklist.md) | `docs/releases/<version>.md` |

GitHub-Issue und Pull Request verlinken die zugehörigen Dokumente. Freigaben enthalten Person, Datum, Umfang und Link zum verbindlichen GitHub-Nachweis.
